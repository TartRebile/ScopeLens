# ScopeLens

ScopeLens помогает сопоставить публичные данные об IP-адресе с инфраструктурой проверяемой организации. Инструмент собирает сведения из реестров, RIPEstat и, по желанию, из баз Censys и Shodan. Результат показывает признаки связи и сохраняет подробности в JSON.

## Что проверяется

- **RDAP:** зарегистрированная сеть, диапазон, страна и сведения об организации.
- **RIPEstat:** объявляемый BGP-префикс, ASN, владелец ASN и PTR.
- **Ключевые слова:** совпадения с названием сети, организацией и доменными именами. Совпадение с данными провайдера отмечается отдельно.
- **Censys и Shodan:** данные из их индексов. Запросы выполняются только с флагами `--censys` и `--shodan`.
- **DNS:** PTR для IP и A/AAAA для найденных имён. Запросы выполняются только с флагом `--active-dns`. Скрипт отдельно запускает и `dig`, и `nslookup`. Для полной проверки должны быть установлены обе утилиты; если какой-то нет, это будет указано в выводе.

Режимы раздельные. Без `--active-dns` выполняется атрибуция через RDAP и RIPEstat. С `--active-dns` выполняются только DNS-запросы: скрипт не обращается к RDAP, RIPEstat, Censys или Shodan и не запрашивает ключевые слова. В обычном режиме запросы идут к RDAP и RIPEstat; Censys и Shodan получают IP только при включённых флагах.

## Запуск

Нужен Python 3.10 или новее. Внешние Python-пакеты не требуются. Для DNS-режима нужны установленные `dig` и `nslookup`. Проверить один адрес:

```bash
python3 scopelens.py --ip 1.1.1.1
```

Проверить файл, где каждый IP указан с новой строки:

```bash
python3 scopelens.py --file hosts.txt
```

Запустить только DNS-проверки либо добавить запросы к базам Censys и Shodan:

```bash
python3 scopelens.py --file hosts.txt --active-dns
python3 scopelens.py --file hosts.txt --censys --shodan
```

При запуске можно ввести ключевые слова и домены через запятую. Enter пропускает эту оценку. Для Censys и Shodan используются переменные `CENSYS_PAT` и `SHODAN_API_KEY`. Если ключ не задан, скрипт запросит его скрытым вводом.

По умолчанию сообщения выводятся на русском. Язык можно переключить флагом `--lang en`. Папка отчётов настраивается флагом `--outdir`.

## Результаты

Для каждого IP создаётся JSON-файл с краткой сводкой и ответами источников. Отчёты сохраняются в папку `scopelens_reports` с датой и временем запуска.

Метка совпадения означает только то, что заданное слово найдено в одном из полей. Реестровые данные могут указывать на провайдера или владельца диапазона, а не на фактического пользователя адреса. Отсутствие записи или совпадения само по себе ничего не решает о принадлежности IP. Результаты рекомендуется точечно перепроверять по каждому спорному адресу и связанным с ним данным.
